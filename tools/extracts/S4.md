- Test every line: is it a requirement, or a solution wearing a requirement's clothes? Could a stranger act on this without one spoken conversation?

## Slide 6

- 6
- Brand Codes Inventory
- Maximum five. The elements that identify you with the logo deleted.
- CODES WE ALREADY HAVE / Colour, shape, sound, typography, character. Only the ones that genuinely repeat.
- CODES WE STILL NEED / What's missing? Write UNKNOWN where nothing exists yet — that's a gap, not an omission.
- OWNER OF EACH CODE / Who approves a change to it? A code with no owner drifts within a month.
- THE NO-LOGO TEST / For each code: would this still identify us if the logo were deleted? Cross out everything that fails.
- Expect this page to get SHORTER as you work. A team that ends with five strong codes on the first pass usually hasn't applied the no-logo test at all.

## Slide 7

- 7
- Multisensory Identity Map
- Six channels. Where one isn't needed, write “not needed, because…” — never blank.
- VISUAL /  / Character, palette, wordmark, layout, application /  / Needed? Who makes it? When?
- VERBAL /  / Tone in trailers, captions, press, in-product copy /  / Needed? Who makes it? When?
- SONIC /  / A motif, ident, or signature sound — separate from the score /  / Needed? Who makes it? When?
- MOTION /  / How things move, appear, and transition /  / Needed? Who makes it? When?
- SPATIAL /  / Venues, lobbies, booths, events, screenings /  / Needed? Who makes it? When?
- INTERACTIVE / BEHAVIOURAL /  / App, game, service behaviour, how you reply to people /  / Needed? Who makes it? When?
- Filling all six enthusiastically is usually wishful thinking rather than ambition. Name who makes each one and when — that's what separates a plan from a wish.
