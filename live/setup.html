Siapkan berkas impor Firebase

Halaman ini hanya berjalan di browser kamu. Daftar NIM tidak dikirim ke mana pun dan tidak disimpan. Hasilnya berupa satu berkas JSON untuk diimpor lewat Firebase console.

Impor ini menimpa seluruh isi database (termasuk jawaban). Pakai hanya sebelum kelas. Untuk menambah satu NIM setelah itu, tambahkan manual di node roster (nama = NIM, nilai = true).
